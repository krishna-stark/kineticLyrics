# Typography sources

These fonts are bundled locally; rendering does not fetch fonts over the network.

- Bebas Neue: https://github.com/google/fonts/tree/main/ofl/bebasneue
- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Each is distributed under the SIL Open Font License in its accompanying OFL file.
The existing LyricDisplay font is Roboto Condensed; its license is also retained.
